# CampoSeguro v4.3.0 — precios fijos en USD y cobertura Sudamérica

Versión de preparación comercial previa al checkout con tarjeta.

## Cambios principales

- Plan Predio: USD 9/mes.
- Plan Campo / Productor: USD 25/mes.
- Plan Institucional: USD 70/mes.
- Se elimina cualquier referencia a precios en bolivianos.
- La página pública aclara que CampoSeguro puede monitorear zonas registradas en Sudamérica.
- El panel cliente incorpora acceso visible a “Activar suscripción”.
- Se mantiene prueba gratuita de 5 días, suspensión por vencimiento y zonas guardadas.
