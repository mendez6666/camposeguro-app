CampoSeguro v4.2.4

Esta versión integra dos cosas antes de pagos con tarjeta:

1. Zonas sin duplicados:
- El botón se bloquea al guardar.
- Se evita crear copias por doble clic.
- Hay botón para eliminar zona.
- Hay limpieza de duplicadas.

2. Control de pago mensual:
- Cada cliente tiene estado de pago.
- Cada cliente puede tener fecha Pagado hasta.
- Si la fecha vence, CampoSeguro suspende al cliente automáticamente.
- No se borran sus zonas.
- El cliente suspendido no recibe alertas ni correos y no accede al panel operativo.
- El admin puede reactivar por 30 días.

## v4.2.4 — prueba gratis 5 días + suspensión automática
- Cliente nuevo puede iniciar con prueba gratuita de 5 días.
- Si la prueba vence y no hay pago, el cliente pasa a SUSPENDIDO automáticamente.
- Si el pago mensual vence, también se suspende automáticamente.
- No se eliminan zonas ni radios: quedan guardados para reactivación.
- El admin tiene botones: Prueba 5 días, Suspender y Reactivar 30 días.
- El monitor y los correos ignoran clientes suspendidos o vencidos.
- Esta versión prepara la integración futura con pasarela de pago por tarjeta.
